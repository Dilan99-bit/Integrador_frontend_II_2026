# Integrador Frontend II 2026

## Estructura del proyecto

```text
src/
├── assets/
│   └── images/
├── components/
│   ├── auth/         # Inicio y registro de sesión
│   ├── common/       # Componentes compartidos entre secciones
│   ├── companies/    # Vistas y proyectos para empresas
│   ├── dashboard/    # Inicio del espacio de trabajo
│   └── students/     # Secciones de estudiantes
├── services/         # Acceso y persistencia de datos locales
├── styles/           # Estilos globales y base
├── App.jsx
└── main.jsx
```

La estructura organiza los archivos existentes sin añadir componentes JSX.
Las carpetas para API, hooks, estado y configuración se incorporarán cuando
el proyecto tenga módulos que correspondan a esas responsabilidades.
